# Legacy

`Universal_Approximation.thy` is the original single-theory draft of this
formalization. It is kept for provenance only: it does not build, since it
imports a `Sigmoid` theory that is no longer part of the development.

It has been superseded by `Universal_Approximation_1d.thy` and the 28 other
theories at the repository root, which carry Theorem 2.1 in the form the rest
of the development builds on.
